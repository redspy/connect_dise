# 오목 (Omok)

- 경로: `games/omok/`
- 모드: 1:1 멀티플레이전 (2인)
- 보드: 13x13
- 통신: Socket.IO + WebRTC P2P (자동 폴백)

## 핵심 아키텍처 및 구현 명세
- **역할 분담**: 호스트(TV/Tablet)가 권위(authority)를 갖고 보드 상태, 턴 관리, 승패 판정을 제어합니다. 모바일 컨트롤러는 돌 놓을 위치 터치 선택 및 확정(착수) 역할만을 전담합니다.
- **클래스 상속**: 호스트는 `HostBaseGame`, 모바일은 `MobileBaseGame`을 상속받아 플랫폼 생명주기 및 렌더링 화면 오버레이 전환(data-phase, data-screen)을 규약에 맞춰 처리합니다.
- **재연결 복구 (Rejoin)**: 로비 단계에서의 새로고침 시 `lobbyState` 동기화 패킷을 내려주어 로비 재연결 프리징 가드를 제공하며, 게임 도중 재연결 시에는 현재 보드판 상태와 턴, 남은 시간을 동기화하는 `rejoinState`를 제공하여 중단 없는 복구가 가능합니다.
- **데모 모드 (Attract Mode)**: 로비 유휴(60초) 시 자동으로 시작되거나 호스트 화면의 데모 버튼을 클릭하여 수동 실행할 수 있습니다. 데모 중 실제 플레이어 접속 시 데모가 즉시 자동 종료되며, 가상 봇(알파오목, 베타오목)이 대국하는 모습을 감상할 수 있습니다.
- **착수 손맛 및 연출**: 돌을 놓을 때의 둔탁한 사운드 큐(Web Audio API 신디사이저), 턴 전환 사운드, 승리 팡파레 효과음이 적용되었으며 모바일 기기에서의 햅틱 진동 피드백(light/heavy), 좌표 선택 시 펄스 애니메이션이 적용되어 있습니다. 호스트 화면에서는 가장 마지막 착수 돌에 링 펄스 애니메이션이 상시 렌더링됩니다.
- **템포 설정**: 클래식(여유 턴 - 시간 무제한)과 퀵 매치(빠른 턴 - 15초 제한)의 2가지 매치 프리셋을 지원하며, 퀵 매치 시에는 15초 턴 타이머가 적용되어 3초 이하 진입 시 경고 톤과 호스트/모바일 화면 경고 애니메이션이 트리거되고, 시간 초과 시 기권패 처리됩니다.
